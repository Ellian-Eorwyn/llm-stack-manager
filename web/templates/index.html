Trusted LAN Only

This manager is intentionally unauthenticated and can perform privileged system changes. Never port-forward it or expose it to the public internet.

1. Machine Preflight

Supported target: Ubuntu 24.04 x86-64 with a working NVIDIA driver. The installer manages the CUDA toolkit, not the kernel driver.

2. Components

The requested local stack is preselected. Required dependencies are selected automatically when this section is saved.

3. Models

For each selected model service, enter a Hugging Face repository, inspect its GGUF files, choose one, and download it. Downloads are resumable and validated before activation.

4. Install and Validate


    

  

  

    
Repair or Remove

    
Repair actions preserve models and configuration. Runtime-service removal keeps the manager available while removing generated backend/tool units and preserving downloaded models.
